The Tools

Help

Using a tool

Press Open tool and load your files as the tool asks. Everything happens on your computer, and nothing is uploaded.

Saving a copy

Download saves a copy that you can use offline, without internet. A saved copy won’t update itself, so check back here for newer versions!

Something not working?

Try a current version of Chrome, Edge, or Firefox. To report a problem or request a change, use Give feedback on the tool’s card.

About These Tools

My name is Ryan Graham and I made these tools "by a teacher, for teachers," to help my PLC do less admin busywork and be able to spend more time on their classes. I wanted to streamline they way we look at assessment data and accommodating our ever growing diverse populations. We're not being paid enough to be data analysts!

I will try to update tools as feedback comes in, and each card shows the current version and what changed.
