Canvas Question Filler

Test building tool · Version 1.0, updated Nov 26, 2026

How to use this tool

This bookmarklet tool allows you to type or paste one question or a whole set of them (question, answer choices, and correct answer) into a single box. Then the Question Filler builds the questions in Canvas for you: it fills in the fields, marks the right answer, sets the point value, turns on Shuffle Choices, and clicks Done. It is made for Canvas New Quizzes (the quiz screen with the Build, Settings, Moderate, and Reports tabs) and multiple choice questions. Always double-check before you publish.

  1. Add the Question Filler button to your browser's bookmarks bar (one time only, below).
  2. In Canvas, open your quiz on the Build tab and then click the new bookmark. This opens the tool.
  3. Paste your questions into the tool's input box, set the points, and click Fill. Sit back and watch it work!
  4. Check everything, fix anything you want, then publish your quiz in Canvas!

  3. Simply paste your questions into the big white box (format below).
  4. Choose your points (see below), then click Fill. For each question, the tool fills in the question and choices, selects the correct answer, sets the points, checks Shuffle Choices, and clicks Done. Then it moves on to the next one.

  6. When you are happy with the quiz, publish it in Canvas as usual.
If the box ever goes away (for example after the page reloads), just click the bookmark again to make it pop back up.
Want to look at a single question before it is saved? Uncheck Click Done when finished and the tool will leave that question open for you.

How to write the questions

Put the question first, then the choices, then the answer. To add more questions, just keep going with a blank line between them. Each question ends with its Answer line.

Which organelle is known as the powerhouse of the cell?
A. Ribosome
B. Mitochondrion
C. Golgi apparatus
D. Lysosome
Answer: B

Which group of organic compounds includes enzymes?
A. Lipids
B. Carbohydrates
C. Proteins
D. Nucleic acids
Answer: C
Points: 2

  • Choices start with a letter and a period or parenthesis: A. or A). Canvas starts with 4 answer boxes, and the tool adds or removes boxes to match how many choices you wrote. Up to 8 choices.
  • Answer: type Answer: C. These are multiple choice questions, so there is one correct answer per question.
  • You can instead put a star at the start of the correct choice, like *C. Proteins, or at the end, like C. Proteins *
  • Points: an optional line like Points: 2 sets the points for just that question (see the next section).
  • A question number at the start (like 1.) is ignored.
  • Rationale lines (like Rationale A: ...) are skipped, since this tool does not fill in answer feedback. They will not cause any trouble if you leave them in.
Tip: you can ask an AI assistant to write questions for you in exactly this format, then paste a whole set at once. Use the Copy Question Template button in the tool to give the AI the format. For very large tests, you may also want to look at Canvas's own import options.

Setting the points

The Points menu in the tool has two choices, and point values can go down to 0.1:

  • each question gives every question the same number of points. Type 1 and every question is worth 1 point.
  • total for all makes the quiz add up to the number you type. Ten questions with a total of 20 are worth 2 points each. If it does not divide evenly, the leftover tenths go to the first questions, so 3 questions with a total of 10 come out to 3.4, 3.3, and 3.3 (always adding up to exactly 10).
  • A Points: 2.5 line inside any question overrides the menu for that question. In total for all, the overridden questions are taken out first, and the rest share whatever points are left.

Under the input box, the tool shows you what it found, like 3 questions detected | 3.8, 3.7, 2.5 | total 10, so you can see the points before you click Fill.

The other buttons and options:

  • Copy Question Template copies a blank question in the right format to your clipboard, ready to paste into the box, a document, or an AI assistant.
  • Title prefix is optional. If you type Bio, your questions are titled Bio 1, Bio 2, Bio 3, and so on. Leave it blank for no titles.
  • Shuffle choices checks the Shuffle Choices box on every question, so answer order is mixed up for each student.
  • Click Done when finished saves each question. When you paste several questions, the tool always clicks Done, because it needs to in order to move on to the next one.
  • Clear box after empties the input box once everything has been built. If the tool stops partway, it keeps the unfinished questions in the box instead.
  • Close removes the tool from the page. Click the bookmark again to bring it back.

Fixing problems

I click the bookmark and nothing happens

Make sure you are on the Build tab of a New Quiz. Some school-managed browsers block bookmark tools. If yours does, send this page's link to your campus tech contact and ask them to allow it.

The tool says it cannot find the Question Stem or the question fields

Click the blue + yourself, start a blank Multiple Choice question so you can see the Question Stem box, and click Fill again. If it still cannot find it, the quiz may be loading inside a frame the bookmark cannot reach. In Chrome, right-click an empty spot in the quiz area, choose This Frame, then Open frame in new tab, and click the bookmark in that new tab.

The tool stopped partway through my questions

The tool tells you why. The questions it already built stay in your quiz, and the ones it did not get to stay in the box with their points already set. Fix the problem (a common one is a red error message on the open question, like a blank answer), click the blue + and choose a Multiple Choice question if it could not add one, and click Fill again.

It could not add a new question by itself

Click the blue + at the bottom of your question list yourself, pick a Multiple Choice question, and click Fill again. The questions that were not built yet are still in the box.

The correct answer is not selected, or the points are wrong

Click the circle next to the right answer yourself, or type the points into the Points box at the bottom of the question. Always check these before publishing. The tool also writes a note under its buttons whenever it could not do one of these steps.

I have fewer than 4 choices, or there are extra empty answer boxes

The tool removes extra boxes when it can. If an empty box is left over, it tells you. Delete it with the trash can icon next to it, since Canvas will not save a question with a blank answer.

Some of my points are not what I expected

Look at the line under the input box before you click Fill. It lists the points for every question. Check that the menu says each question or total for all the way you meant it, and look for any Points: lines in your questions.
