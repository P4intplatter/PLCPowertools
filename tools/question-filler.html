Eduphoria Question Filler

Test building tool · Version 1.0, updated Nov 26, 2026

How to use this tool

Type or paste a whole multiple choice question, and the Question Filler fills in the question, every answer choice, the correct answer, and the rationales for you. You still check it before you save.

  1. Add the Question Filler button to your browser's bookmarks bar (one time only, below).
  2. In Eduphoria, open a question to edit and click the bookmark.
  3. Paste your question into the box and click Fill.
  4. Check everything, fix anything you want, then click Update in Eduphoria.

Everything runs inside your own browser. Nothing you type is sent anywhere.

  2. Drag the blue button below up onto that row, then let go. Do not click it here, only drag it.

Step 2: Build a question

  1. Log in to Eduphoria and open your test. Start a new question (or edit one) so you are on the Edit Question screen with Selected Response chosen.
  2. Click Question Filler on your bookmarks bar. A box appears in the middle of the screen. You can drag its blue top bar to move it, and click the bar to collapse it.
  3. Paste your question into the big white box (format below).
  4. Click Fill. In a second or two the question, choices, correct answer, and rationales appear on the page.
  5. Check it. Read the question, make sure the right answer is selected, and edit anything you like.
  6. Click Update at the bottom right of Eduphoria to save.
If the box ever goes away (for example after the page reloads), just click the bookmark again.

How to write the question

Put the question first, then the choices, then the answer. Rationales are optional.

Which one of the cells shown is eukaryotic?
A. The cell that contains the nucleus
B. The cell that contains the ribosomes
C. The cell that does not contain the nucleus
D. The cell that contains cytoplasm
Answer: A
Rationale A: Eukaryotic cells have a nucleus.
Rationale B: Both kinds of cells have ribosomes.

  • Choices start with a letter and a period or parenthesis: A. or A). Up to 8 choices.
  • Answer: type Answer: C. For a Multiple Selection question, list more than one, like Answer: A and C. The tool switches the question type for you.
  • You can instead put a star at the end of the correct choice(s), like C. The cell that does not contain the nucleus *
  • Rationales: Rationale A: ... goes with choice A, and so on. A single Rationale: ... with no letter goes with the correct answer.
  • A question number at the start (like 1.) is ignored.
Tip: you can ask an AI assistant to write questions for you in exactly this format, then paste them one at a time.

Adding pictures

  1. Copy a picture (or take a screenshot), click inside the Question Filler box, and press Ctrl + V. You can also drag a picture file onto the box or click + Image.
  2. A small thumbnail appears with a menu. Choose where it goes: above the question text, below it, or inside a particular answer choice.
  3. Click Fill. The picture is added along with the text.
After you save, reopen the question once to make sure the picture shows. If it is missing, add that picture with Eduphoria's own picture button instead.

The other buttons

  • Clear all empties the question (picture included), every choice, and every rationale on the page so you can start over. It asks you to confirm first.
  • Scan outlines in red the boxes the tool found and labels them Question, Answer, and Rationale. Use it if something lands in the wrong place.
  • Question box menu: append adds your text after anything already in the question box (so a picture you inserted stays), replace wipes the box first, leave alone skips it.

Fixing problems

I click the bookmark and nothing happens

Make sure you are on the Eduphoria Edit Question page. Some school-managed browsers block bookmark tools. If yours does, send this page's link to your campus tech contact and ask them to allow it.

Text went into the wrong boxes

Click Clear all, then Scan. If the red labels do not match the boxes on the page, tell the person who runs this page what you see.

The correct answer is not selected

Click the circle (or box) next to the right response yourself. Always check this before saving.

I have more choices than Eduphoria shows (or fewer)

If there are too few response boxes, the tool tells you. Add a response on the page, then click Fill again. If there are extra empty responses, delete them with the trash can icon next to each.
